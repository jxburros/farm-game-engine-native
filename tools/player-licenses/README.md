# Player license notices

`THIRD-PARTY.txt` is the license notice file of the game player. Every player
template ships it, Export Game copies it to `licenses/THIRD-PARTY.txt` in
every exported game, and the editor ships it as `licenses/THIRD-PARTY-rust.txt`
(its engine library is built from crates inside `farm-player`'s graph).

`generate.sh` writes it:

1. [cargo-about](https://github.com/EmbarkStudios/cargo-about) lists the Rust
   crates in `farm-player`'s dependency graph for the Windows and Linux
   targets, with their license texts (`about.toml` lists the accepted
   licenses, `about.hbs` is the template);
2. it appends what cargo-about can't see: the Inter and Atkinson Hyperlegible
   fonts (`assets/fonts`), the plugin sandbox guest that `farm-plugins` embeds
   (quickjs-ng, rquickjs-sys, wasi-libc with musl and cloudlibc; texts in
   `plugin-guest/`), and the player's own MIT license (`LICENSE`).

```sh
cargo install cargo-about --locked --features cli   # CI uses 0.9.2
tools/player-licenses/generate.sh                   # rewrite THIRD-PARTY.txt
tools/player-licenses/generate.sh --check           # fail when it is out of date (CI)
```

Run it after changing `farm-player`'s dependencies, the embedded fonts, or the
plugin guest's dependencies, and commit the result. The editor's own .NET
notices are generated by [`tools/editor-licenses`](../editor-licenses/generate.mjs).
